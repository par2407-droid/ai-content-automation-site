AI Content Automation

Public information page for the TikTok Developer app “AI Content Automation”.

Status: This app has not been approved by TikTok, and it does not currently have Content Posting API access. Approval for Direct Post is still pending. Nothing described below as TikTok posting is available until TikTok approves the app and the account owner authorizes it.

What it is

AI Content Automation is a personal, local-first tool that helps one creator prepare short vertical (9:16) videos, mainly movie-review videos, for TikTok, Instagram Reels and YouTube Shorts. The creator remains in control at every step: editing starts only when the creator presses a button, previews are reviewed by the creator, and publishing happens only after the creator approves it for a specific platform.

This website versus the application

  • This website is a small static information site (three pages). It has no login, no backend, no cookies and no analytics, and it does not process videos or accounts.
  • The application runs only on the creator's own Mac (a dashboard at localhost and a local backend). It is not hosted online, has no public user accounts and cannot be used by the public. Its source code and files are not published here.

Intended TikTok integration

The intended use is the official TikTok Content Posting API with Direct Post, for one creator account (@official_putrasabah), to post that creator's own videos after the creator reviews and approves them. Planned behavior:

  • The creator signs in with TikTok and authorizes the app (OAuth) for their own account.
  • The app reads the account's posting options from TikTok and the creator chooses who can view the post and the interaction settings. There are no defaults.
  • The creator explicitly confirms each post. Nothing is posted automatically, on a schedule, or without that confirmation.

Until TikTok approves the app and the account owner authorizes it, the creator publishes to TikTok manually and records the result in the local app.

Implemented today and planned

  • Implemented in the local app: editing of movie-review videos, previews and final renders; caption and metadata drafts; a manual publishing record for TikTok, Instagram Reels and YouTube Shorts; publishing to the creator's own YouTube channel after the creator confirms the channel and each upload; optional outbound status notifications (macOS pop-ups and, if the creator sets it up, a Telegram message).
  • Planned, not yet working: TikTok sign-in and TikTok Direct Post. The app contains an unfinished TikTok code path that has never been run against TikTok, and no TikTok authorization flow exists yet.

AI and external services

The app does not send videos, transcripts or captions to any external AI service. Speech recognition, caption drafting and visual matching run on the creator's own computer using locally stored models. Data goes to a platform only when the creator publishes there.
