1. What this is

AI Content Automation is a personal, local-first tool run by one individual on their own computer to prepare short vertical videos and, with the creator's confirmation, publish them to the creator's own accounts. It is not a public service: there are no public accounts, no sign-up and no hosted version. This website only provides information about it.

2. What the application does

  • Helps edit movie-review videos from clips, narration, a trailer and a poster the creator supplies.
  • Renders a low-resolution preview first; a final render is made only after the creator approves the preview.
  • Drafts captions, titles and hashtags for the creator to review and edit.
  • Publishes only after explicit creator approval for a specific platform. Nothing is published, scheduled or started automatically.

3. Platform authorization and approval

Posting to TikTok through the official Content Posting API requires TikTok's approval of the application and the account owner's authorization. That approval is pending and may not be granted. TikTok sign-in and Direct Post are not implemented yet; today TikTok posting is done manually by the creator, who records it in the app. YouTube publishing uses the creator's own OAuth authorization and Google's API terms. The platforms' own terms, community guidelines, content rules and API limits apply and take precedence.

4. Limitations

  • Generated edits, captions and drafts may contain mistakes, including spelling, wording or factual errors. The creator must review everything before publishing.
  • The tool does not analyse the footage itself to verify claims or detect rights problems.
  • The creator is responsible for having the rights to all material used (clips, trailers, music, images) and for complying with copyright and platform rules.
  • Platform APIs can change, limit or refuse requests, so publishing may fail or be delayed.

5. Acceptable use

The application is to be used only with the operator's own accounts and own content, and not for spam, automated bulk posting, deception, or any use that breaks platform rules or the law.
