Privacy Policy

Last updated: 20 November 2026

AI Content Automation is a personal tool run by one individual on their own computer. It is not a hosted service and has no public user accounts. TikTok Direct Post approval is still pending.

1. Who this applies to

This policy describes how the application handles data. The only person who uses the application is its creator and operator, who authorizes it with their own TikTok and YouTube accounts. It is not offered to the public and it does not collect data from visitors of other people's accounts.

2. This website

This static website does not use cookies, analytics, advertising, forms or tracking, and it does not collect personal information from visitors. Like any website, the hosting provider (GitHub Pages) may keep ordinary technical logs under its own privacy statement.

3. Data the application handles

  • Content the creator provides: video clips, audio, images, scripts and project settings, stored in folders on the creator's computer.
  • Generated drafts: edit plans, previews, final videos and caption/metadata drafts, stored on the same computer.
  • Authorization data: when the creator connects YouTube, the application stores the OAuth access and refresh tokens it receives and the connected channel's name and ID. TikTok sign-in is not implemented yet, so no TikTok token or TikTok account data is collected today. If TikTok approves the app and the creator authorizes it, the app is intended to store the OAuth token and use the posting options and account display information returned by the API to build the posting screen, and this policy will be updated.
  • Posting records: the platform, date, visibility choice, status, and link of posts the creator published.
  • Notifications: the app shows macOS pop-ups and a list in the dashboard. If the creator sets up their own Telegram bot, short status messages (for example “preview ready”) are sent to that one chat. These messages do not contain transcripts, error details, files or links.
  • Optional public statistics: if the creator adds a YouTube API key or enters numbers by hand, the app can read the public statistics of the creator's own videos.

4. How the data is used

Data is used only to prepare the creator's videos, show previews, and, after the creator's explicit confirmation, publish the creator's own approved video to the creator's own account. OAuth tokens are used only to call the platform's API for that purpose. Data is not sold, shared for advertising, or used to profile anyone.

5. Storage and access

Everything is stored locally on the creator's computer, in the application's folders. Client credentials are kept in a local configuration file that is excluded from version control, and OAuth tokens are kept in local files restricted to the owner's user account. No cloud database is operated for the application. Access is limited to whoever has access to that computer and user account. Local files are protected only by the computer's own security measures, and no absolute security guarantee is made.

6. Third parties

Data leaves the computer only in these cases: the approved video and caption are uploaded to a platform the creator chose and confirmed (currently YouTube; TikTok only if approved in future), under that platform's terms and privacy policy; the YouTube sign-in and channel lookup go to Google; optional Telegram status messages go through Telegram; and optional public statistics are requested from YouTube. No video, audio, transcript or caption is sent to any external AI service: speech recognition, caption drafting and visual matching run locally on the creator's computer.

7. Retention

Data stays on the computer until the creator deletes it. The application does not delete project files, videos or records automatically (it only removes its own temporary working files). Stored OAuth tokens stay until the creator presses Disconnect or deletes the file.

8. Deletion and revoking access

  • The creator can press Disconnect for YouTube in the application, which deletes the stored token file (including the saved channel name and ID) from the computer. This does not revoke access at Google, so also revoke it as described below. There is no TikTok connection to disconnect yet.
  • Access can also be revoked from the platform: in TikTok under Settings and privacy, Security and permissions, Apps and websites permissions, and for Google at myaccount.google.com/permissions.
  • Posts already published on a platform are controlled through that platform.
  • Local files, previews, final videos and posting records are not removed by Disconnect; the creator deletes them from the application folders on their computer.
  • To ask about data, contact the address below.

9. Children

The application is not directed to children and does not knowingly collect children's data.
